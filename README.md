# Mihira-Vedula-CS193-Final-Project
This is my final project for the CS19300 class. It is a language learning (specifically vocabulary learning) game where users are able to enjoy learning words by unscrambling 15 scrambled words and checking their score at the end. This game is played through the terminal. 

A file of vocabulary words will be processed and scrambled. Only 15 words will appear on the screen one at a time. For each word, there is user input where the user can enter their answer. If it is correct, a point will increase. After 15 words, the game will end and the score will be displayed. In the first version, there is only going to be one given vocab list processed. 

In later versions, however, future goals include having more vocabulary list options, letting users import their own lists, jumbling up words instead of going in order, and incorporating special characters such as accents and tildes in Spanish. Also, the ability for the user to end the game early or have several attempts per question could be included. 

Tech stack for this project: 
This project is written Java. Some classes in the IO library, such as BufferedReader and FileReader are used. Other than that, the ArrayList class and Random classes are used from the java.util library.
